# 🐍 Snake Game (Python)

A classic **Snake Game** built using Python’s `turtle` graphics module.  

Control the snake, move around the screen, and enjoy smooth gameplay! 🎮🐍  

---

## 📌 About the Project

<details>
<summary><strong>▶ What does this project do?</strong></summary>

This project is a graphical implementation of the **Snake Game**.

The player controls a snake using keyboard inputs:

- ⬆️ Move Up  
- ⬇️ Move Down  
- ⬅️ Move Left  
- ➡️ Move Right  

The snake moves continuously across the screen, and the game updates in real time.

This project helps practice:

- 🎨 Turtle graphics  
- 🎮 Event listeners (keyboard input)  
- 🔁 Game loops  
- 🧠 Object-Oriented Programming  
- ⏱️ Animation using `time.sleep()`  

</details>
